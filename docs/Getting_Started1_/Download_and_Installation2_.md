# Download and Installation

Follow the undermentioned steps to download and install Midum on Windows:

1. Download the setup executable (Midum-Setup.exe) from the [latest release page](https://github.com/parth-satija/Midum/releases/latest) or click [here](https://github.com/parth-satija/Midum/releases/latest/download/Midum-setup.exe) to start the download directly.
2. Run the setup executable and follow the steps.
3. Tesseract-OCR: The setup will give you an option to install Tesseract-OCR. It is a lightweight tool that unlocks OCR-based computer control abilities to Midum. It allows Midum to — with your permission, and when you tell it to — read the text on your screen. Midum still works without it, with only the few tools dependent on it being unavailable.
